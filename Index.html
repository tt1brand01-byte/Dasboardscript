📘 Panduan Setup (sekali saja)
1

Buat Google Sheet baru

Boleh spreadsheet kosong — sheet "ScriptKonten" dengan header akan dibuat otomatis oleh script di langkah berikutnya.

2

Buka Apps Script

Di spreadsheet: menu Extensions → Apps Script. Hapus kode default, lalu tempel kode di bawah ini.

3

Deploy sebagai Web App

Klik Deploy → New deployment → pilih tipe Web app. Isi "Execute as: Me" dan "Who has access: Anyone". Klik Deploy, izinkan akses, lalu salin URL yang muncul.

4

Tempel URL di sini

Paste URL hasil deploy ke kolom "URL Web App Apps Script" di sebelah kiri, lalu klik Simpan & Hubungkan. Setelah itu semua script otomatis tersinkron dua arah.
